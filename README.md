# AI认证问答系统

这是一个基于Web的AI认证问答系统，可以帮助你测试和提升AI相关知识。

## 功能特点

- 🎯 交互式问答界面
- 📊 实时进度跟踪
- ✅ 即时答案反馈
- 📝 详细解释说明
- 📈 答题统计报告
- 🎨 现代化UI设计
- 📱 响应式设计，支持移动设备

## 使用方法

### 1. 启动服务器

在终端中运行以下命令启动本地服务器：

```bash
python server.py
```

### 2. 访问应用

打开浏览器，访问：
```
http://localhost:8000
```

### 3. 开始答题

1. 点击"开始答题"按钮
2. 阅读问题并选择答案
3. 点击"提交答案"查看结果
4. 查看详细解释
5. 点击"下一题"继续

```
aif-cert/
```

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **后端**: Python 3.x
- **数据格式**: JSONC (JSON with Comments)

## 自定义问题

你可以通过编辑 `questions.jsonc` 文件来添加或修改问题。每个问题的格式如下：

```json
{
  "id": "Question 1",
  "question": "问题内容...",
  "answers": "A. 选项A\nB. 选项B\nC. 选项C\nD. 选项D",
  "correct_answer": "B",
  "explanation": "详细解释..."
}
```

## 故障排除

### 问题：无法加载问题数据
- 确保 `questions.jsonc` 文件存在且格式正确
- 检查服务器是否正常启动
- 查看浏览器控制台是否有错误信息

### 问题：页面显示异常
- 清除浏览器缓存
- 尝试使用不同的浏览器
- 检查网络连接

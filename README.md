# AI认证问答系统

这是一个基于Web的AI认证问答系统，可以帮助你测试和提升AI相关知识。

## 功能特点

- 🎯 交互式问答界面
- 📊 实时进度跟踪
- ✅ 即时答案反馈
- 📝 详细解释说明
- 📈 答题统计报告
- 🎨 现代化UI设计
- 📱 响应式设计，支持移动设备
- 🔍 **错题筛选功能** - 支持输入错题ID列表，只练习指定题目
- 🎮 **双模式答题** - 全部题目模式和错题练习模式
- 📋 **题目导航器** - 可视化题目导航，支持跳转和状态显示

## 使用方法

### 1. 启动服务器

在终端中运行以下命令启动本地服务器：

```bash
python server.py
```

### 2. 访问应用

打开浏览器，访问：
```
http://localhost:8000
```

### 3. 选择答题模式

系统提供两种答题模式：

#### 全部题目模式
- 练习所有可用题目
- 适合全面复习和测试

#### 错题练习模式
- 只练习指定的错题
- 输入错题ID列表（每行一个）
- 例如：
  ```
  Question 1
  Question 5
  Question 10
  ```

### 4. 开始答题

1. 选择答题模式
2. 如果选择错题模式，输入错题ID列表
3. 点击"开始答题"按钮
4. 阅读问题并选择答案
5. 点击"提交答案"查看结果
6. 查看详细解释
7. 点击"下一题"继续

### 5. 使用题目导航器

- 点击"题目导航"展开导航面板
- 绿色圆圈：已答对的题目
- 红色圆圈：答错的题目
- 蓝色圆圈：当前题目
- 点击任意圆圈可跳转到对应题目

## 自定义问题

你可以通过编辑 `questions.json` 文件来添加或修改问题。每个问题的格式如下：

```json
{
  "id": "Question 1",
  "question": "问题内容...",
  "answers": "A. 选项A\nB. 选项B\nC. 选项C\nD. 选项D",
  "correct_answer": "B",
  "explanation": "详细解释..."
}
```

## 故障排除

### 问题：无法加载问题数据
- 确保 `questions.json` 文件存在且格式正确
- 检查文件路径是否正确
- 查看浏览器控制台是否有错误信息

### 问题：页面显示异常
- 清除浏览器缓存
- 尝试使用不同的浏览器
- 检查网络连接

### 问题：错题筛选不工作
- 确保错题ID格式正确（例如：Question 1）
- 检查ID是否存在于questions.json文件中
- 确保每个ID占一行

## 快速开始

### 方法一：直接打开
1. 下载项目文件
2. 双击 `index.html` 文件在浏览器中打开

### 方法二：本地服务器
```bash
# 使用Python启动本地服务器
python3 -m http.server 8000

# 或使用Node.js
npx http-server

# 然后在浏览器中访问 http://localhost:8000
```
